# ch3ny 的校园寻宝

一款面向 CTF 新生的 Windows 单机文字冒险小游戏。招新日，ch3ny 学长递给你一份校园地图；从校门口出发，自由探索校园，与校队成员交谈，找回丢失的礼物袋。

## 下载与运行

下载 [Windows x64 游戏压缩包](releases/misc5-campus-treasure-windows-x64.zip)，解压后双击 `misc5-campus-treasure.exe`，或在终端中运行。无需安装 Python，也无需连接服务器。

## 基本操作

游戏开始后输入 `help` 查看完整命令。常用命令：

| 命令 | 用途 |
| --- | --- |
| `look` | 观察当前位置 |
| `map` | 查看地图与当前位置 |
| `go 北` | 按方向移动，也支持南、东、西 |
| `choose 1` | 体验当前位置的事件 |
| `talk <人物>` | 与在场人物交谈 |
| `ask <话题>` | 选择交谈话题 |
| `say <内容>` | 说出自己的发现 |
| `inventory` | 查看背包 |
| `read <物品>` | 查阅背包中的物品 |
| `status` | 查看当前经历 |

游戏没有限时，走错路可以返回。留意事件描述，并在需要时回看地图、背包和帮助。
